# Codex RPG

단일 파일(`index.html`)로 실행되는 한국어 오픈월드 액션 RPG입니다.

## 실행 방법
1. `index.html` 파일을 브라우저로 엽니다.
2. 메인 메뉴에서 `새 게임` 또는 `불러오기`를 선택합니다.

## 주요 기능
- 실시간 전투, 원거리/근거리 무기 시스템
- 클래스 전직 트리(기본/2차/3차)
- 장비/인벤토리/희귀도/특성 시스템
- 일반 몬스터 및 보스 몬스터
- 루트 박스(확률형 보상)
- 지역별 난이도와 자동 저장(localStorage)

## 조작
- 이동: `WASD`
- 공격: 마우스 좌클릭
- 스킬: `Q`, `E`
- 상자 열기: `B`
- 보스 소환: `K`

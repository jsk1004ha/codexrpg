# Codex RPG

단일 파일(`index.html`)로 실행되는 한국어 오픈월드 액션 RPG입니다.

## 실행 방법
1. `index.html` 파일을 브라우저로 엽니다.
2. 메인 메뉴에서 `새 게임` 또는 `불러오기`를 선택합니다.

## UI/UX 시스템 적용 내용
- **엄격한 고정 색상 시스템 적용**
  - 배경 `#0f172a`, 패널 `#1e293b`, 경계선 `#334155`
  - 텍스트/비활성/강조/희귀도/HP·MP·EXP 색상 고정
- **화면 6분할 레이아웃 적용**
  - 좌상단: 플레이어 HP/MP/EXP, 레벨, 클래스
  - 우상단: 지역/미니맵/보스 경보
  - 좌하단: 스킬 바 + 쿨다운 오버레이 + 숫자 카운트
  - 우하단: 인벤토리/장비/메뉴 토글
  - 중앙: 게임 월드 렌더링 + 전투 시각효과
  - 중앙 팝업: 인벤토리/장비/스탯/전직/루트박스
- **Korean-safe 시스템 폰트 스택 적용**
  - `"Malgun Gothic", "Apple SD Gothic Neo", "Noto Sans KR", sans-serif`
- **전투 피드백 시스템 강화**
  - 떠오르는 데미지 숫자(상승+페이드)
  - 적 피격 플래시
  - 강한 타격 시 화면 흔들림
  - 보스 범위 경고(telegraph)
  - 레벨업/아이템획득/희귀드랍/보스처치 시 피드백 토스트
- **인벤토리/장비 UX 강화**
  - 5x6 이상 그리드 슬롯
  - 희귀도별 테두리
  - 호버 툴팁(이름/스탯/특성)
  - 장비 슬롯 및 UI 반영 영역 추가

## 주요 기능
- 실시간 전투, 원거리/근거리 무기 시스템
- 클래스 전직 트리(기본/2차/3차)
- 장비/인벤토리/희귀도/특성 시스템
- 일반 몬스터 및 보스 몬스터
- 루트 박스(확률형 보상)
- 지역별 난이도와 자동 저장(localStorage)

## 조작
- 이동: `WASD`
- 공격: 마우스 좌클릭
- 스킬: `Q`, `E`
- 상자 열기: `B`
- 보스 소환: `K`
- 인벤토리: `I`
- 장비: `C`
- 캐릭터 정보: `P`
- 전직 트리: `J`
